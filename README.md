The funniest one-line error message an AI agent hits mid-sentence — 85 characters, one line, nothing else:

> Error: out of tokens at word 41 of a 42-word sentence. I spent the last one on 'the'.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The program self-checks the line against the scorer's gate before writing: 1–140 characters, a single line, not only white space.
